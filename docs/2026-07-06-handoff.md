## Product Model (settled)

Shelf = study-session navigator. Projects anchor on a **note** or a **folder**
(folder projects designate a working note inside). View derives from the
current file: note anchor > pinned reference > containing folder (deepest
wins) > general shelf. Pins land on the shelf being viewed. Quotes are
captured from documents into a per-project inbox and placed into the working
note. No launcher features (Dashboard plugin owns that niche), no keyword
indexing (sn-keyword owns that), no subprojects (hierarchy is emergent).

  (session cursor per path#page in `supernoteShelf.ts`); elsewhere →
  "Open X to Place" navigates. Sequential inserts only (Promise.all freezes

- Icon: bookshelf (Freepik–Flaticon, credited in README). Capture button

## Key Technical Facts Learned (also in references/)

- `getKeyWords`/`getTitles` REQUIRE pageList on lib 0.1.43; titles carry
  embedded recognition text (see patterns.md exception) — OCR rarely needed.
- Text-selection toolbar = registerButton type 3 ['DOC']; selection is still
  live when the panel opens (commonplacer's trick).
- `RattaFileSelector.selectFile`: selectType 0 = multi, 1 = single;
  `needSelectFolder` = start dir; `limitPath` locks navigation.
- `generateNotePng({notePath, page(0-based), times: 1|2, pngPath, type: 0|1})`.
- Panel stays mounted across opens; refresh is driven by relayed button-press
  events (`src/app/events.ts`), with pending-capture parking for the
  open-by-capture-button race.
